# Sale detail review screenshots

These phone and tablet screenshots render `SaleDetailNativeView` with synthetic
sale and employee fixtures in `SaleDetailSnapshotTests`. They show the salesperson
picker and Save action in separate list rows, and historical tire details without
substituting another catalog item. No live customer data or payment is used.

Regenerate them by running the `SaleDetailSnapshotTests` test class. The images are
written to the simulator app's `Documents/SaleDetailVisualQA` folder and attached
to the XCTest result bundle. Copy the selected images here for pull-request review.
